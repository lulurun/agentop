# Plugins

Optional features built on the agentop core. How plugins work (manifest, loader, API, UI slots, enable and disable) is in [design.md section 12](design.md#12-plugins).

| Plugin | What it does | Status | Docs |
|--------|--------------|--------|------|
| Dialogues (`dialogue`) | Two agents work together on one task. An orchestrator passes messages between them, following a scenario. The app's Dialogues feature starts them with a wizard that fills in the scenario's brief, shows both agents side by side (live and read-only while running, as transcripts after), with stats and artifacts on the right; their sessions are left out of the session list. `agentop dialogue` starts and manages them too | Built: moved into a plugin 2026-11-14; workspace 2026-11-15 | [dialogue.md](dialogue.md), [design 12.9](design.md#129-dialogues-as-a-plugin) |
| Waiting for input (`attention`) | Marks a session "Waiting" in the list once its agent was working and its screen has then stayed the same for 4s; any later change clears it. The open session is never marked. It watches the first pane of each session's first window, where agentop starts the agent, on the service's 2s tick: one `tmux list-panes -a` for all sessions, plus a `capture-pane` of the visible screen only for panes that printed something. The service's Status tab shows what each tick costs; turn the plugin off there and it costs nothing | Built 2026-11-15 | [design 12.8](design.md#128-first-plugins) |
| File viewer (`viewer`) | Opens a file from the right panel (the working directory, or the agent tool's memory folder) in a main-area tab, as plain text with line numbers. A file from the Changed list opens as its diff against HEAD (staged and unstaged together, deleted and new files too), with Open file to see its text. A Markdown file opens drawn (tables, task lists, its images, and links to files beside it opening in tabs), with Raw beside it; an image file (PNG, JPEG, GIF, WebP, AVIF, BMP, ICO or SVG, up to 5 MB) opens drawn in the middle of the tab; a transcript can still be read as a conversation. Text files, and fenced code blocks in Markdown, are coloured by language: 20 highlight.js grammars registered by hand (`ui/src/plugins/viewer/highlight.ts`), loaded only when a file is opened; other files, and files over 512 KB, stay plain | Completed 2026-11-15 | [design 12.6](design.md#126-ui) |
| Memory (`memory`) | Keeps agentop's own copy of every agent transcript on the host, never deleted, then builds a searchable record of prompts and replies from it, with a model's summary of each session. The Memory feature searches it, opens a conversation at the hit, and shows the session's summary; searches and misses are noted to decide on embeddings | Built: archive, messages table, conversation view, recall (`agentop recall`, the `recall` skill), summaries (Claude Code or Codex), the Memory feature, recall misses | [design 12.11](design.md#1211-memory-agentops-own-record-of-conversations) |
| Email code (`email-code`) | A way to sign in without the service token. The sign-in screen gets "Send me a sign-in code"; the service mails a 6-digit code to the one address in `~/.agentop/plugins/email-code/config.toml`, and answers only "Code sent". A code works for 10 minutes, once, and only with the request ID the asking browser got back; 5 wrong tries end it, and codes are sent at most once a minute and 5 times an hour. Signing in adds an ordinary client. Off by default; `agentop email-code test` checks the settings | Built 2026-11-16 | [design 7.4](design.md#74-ways-to-sign-in-2026-11-16), [README](../README.md#secure-setup) |
| Input bar (`input`) | A box below a session's terminal to type prompts in, for phones, with buttons for Esc, the arrows, Enter, Tab, Shift-Tab and 1–3, and ^B for tmux's prefix (^B then `c` makes a window). While it shows, the terminal is only watched (it still scrolls and fits the screen). A prompt is typed in the way `agentop send` does it. Each device chooses whether the bar shows (touch screens by default), and its ⌨ button switches back to typing in the terminal. Only for running sessions agentop started. Off by default | Built 2026-11-17 | [design 12.12](design.md#1212-input-bar-type-prompts-in-a-box-for-phones) |
| Project groups | Group sessions by project in the left panel | [Backlog](backlog.md#features) | [design 12.8](design.md#128-first-plugins) |

Handoff is not a plugin: `agentop send` and the `handoff` skill pass a side task to another session ([design 12.10](design.md#1210-handoff-pass-a-side-task-to-another-session)).
